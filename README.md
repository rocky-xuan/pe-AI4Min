# Data for pe-AI4Min
The data in this work was selected based on our previous work (https://github.com/GCaptainNemo/Electronegativity-Under-Pressure/blob/main/data/augment_en_pressure.csv). The raw data can be found in the file augment_en_pressure.csv in the folder, while the processing workflow and the feature importance obtained from the screening are shown in the figure below. Finally, 10 features were selected for training our KAN model.
![fig1](https://github.com/user-attachments/assets/6fa5a065-2e79-457a-bf4c-78261e649520)

If you would like to use our algorithm and workflow, please visit http://pe.ai4mineral.com/
. There you can freely access our functions to compute, analyze, and visualize Electronegativity, Work function, Bond energy, Chemical affinity, and Formation energy.
